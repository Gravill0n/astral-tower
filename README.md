# Astral Tower

A single-player browser incremental/management game. A wizard's tower orbits a star, grows floor by floor and unlocks five modules in a fixed order:

1. **Arcane Foundry**: ratio puzzle (ore → refined → parts → enchanted items), mana grid, floor space
2. **Starlight Gardens**: crops timed against a real-time constellation clock
3. **Star-Sailors' Guild**: voyages with risk, pace and captain choices
4. **Constellation Library**: study relics, light constellation stars for permanent bonuses
5. **Celestial Bestiary**: hatch and breed familiars for traits

When the star turns Red Giant, the player can go **Supernova**: the run resets for Stardust, and after 5 Supernovas a Galaxy map lets the player pick the next star.

Cozy by design: shortages slow things down, nothing is ever lost.

## Platform targets

- Browser, desktop and mobile with equal priority
- Installable (PWA) and playable offline
- English only in 1.0
- Real-time constellation clock; offline progress up to 24 h
